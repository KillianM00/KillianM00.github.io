Case study / Defensive security

Hostcheck — Cross-Platform Host Posture Diagnostics

A local diagnostic tool that translates operating-system security settings into structured findings and concrete remediation guidance. Platform-specific adapters gather evidence while a shared result model supports terminal, JSON, and optional GUI reports.

Native OS evidence → normalized finding → remediation

The engineering problem

Operating systems expose security posture through different tools and output formats. A usable diagnostic system needs to normalize evidence while retaining enough detail for someone to understand and act on a finding.

Platform adapters, shared results

PowerShell and shell-command adapters gather Windows, Linux, and macOS observations. A common result model carries status, finding code, and details into terminal, JSON, and optional GUI presentations.

Readable output and testable behavior

Stable finding codes map observations to explanations and remediation guidance. Mocked command execution tests parsing and reporting without altering a real host. The local suite passed 85 tests.

Scope of the assessment

These are selected posture checks. OS version, permissions, and tool availability affect coverage. A passing report does not certify that a machine is secure or replace a complete vulnerability assessment.

Current scope

Posture checks cover selected settings and depend on OS version and permissions. A passing report is not a security certification or a complete vulnerability assessment. The November 2026 mocked test run passed 85 tests; live behavior across every supported OS was not revalidated.

Technical focus

Python · PowerShell · native OS utilities · JSON
